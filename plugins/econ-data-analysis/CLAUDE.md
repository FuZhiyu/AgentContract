# econ-data-analysis

Principle-based guide for rigorous economic data analysis. Three core principles
apply concurrently at every stage — they are not sequential phases.

## Principles

1. **Description Before Analysis** — describe data thoroughly before and after every transformation
2. **Logs and Documentation** — use jupytext percent format; interleave code, narrative, and outputs; track row counts at every sample-changing operation
3. **Multi-Source Validation** — verify scale, properties, and relationships against economic intuition and published references

## Conventions

- This plugin is instruction-only (no executable scripts)
- Pitfall checklists are inline in SKILL.md so agents always see them
- Reference files are for supplementary material (robustness checks, jupytext syntax)
- Supports Python and Julia equally
